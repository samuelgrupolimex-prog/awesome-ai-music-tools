# Contributing

Thank you for your interest in contributing!

## How to Contribute

1. **Fork this repository**
2. **Make your changes** — add content to README.md in the appropriate section
3. **Follow the existing format** — use tables, code blocks, and clear descriptions
4. **Test your contribution** — verify that prompts/examples produce the described result
5. **Submit a Pull Request** with a clear title

### Quality Guidelines

- Content must be specific and tested, not generic
- Use lowercase-hyphenated format for tags
- Avoid trademarked or artist names where possible
- Include specific examples, not vague descriptions

### Reporting Issues

Found an error or have a suggestion? [Open an issue](https://github.com/suno-ai-farm/awesome-ai-music-tools/issues/new).

## Code of Conduct

Be respectful. We're all here to make better AI music together.
